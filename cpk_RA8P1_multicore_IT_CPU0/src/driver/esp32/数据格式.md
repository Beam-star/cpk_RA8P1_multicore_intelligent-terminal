# RA8P1 ↔ ESP32 串口通信数据格式

## 概述

ESP32 上已部署云端大模型 API 接口：ESP32 用自带麦克风采集语音流 → 上传云端大模型 →
拿到文字结果 → 通过串口把 UTF-8 中文发给 RA8P1。RA8P1 负责发命令、收中文、显示字幕、
存会议记录。

- 串口：**UART2 / SCI2，P801（TXD2）/ P802（RXD2）**
- 参数：**115200 bps，8 数据位，无校验，1 停止位（8N1）**
- 三个功能模式（`0x01`/`0x03`/`0x06` 主模式互斥）：
  1. **实时语音转文字（ASR）**：识别结果实时显示，并在 ASR 模式下保存为会议记录 txt。
  2. **AI 智能体对话（AI）**：与云端大模型多轮对话，结果实时显示（不保存）。
  3. **PPT 翻页（PPT）**：Hand 检测模式下识别手掌左右滑动，发翻页命令给电脑。

## 数据流

```text
┌─────────┐ 命令(0x01~0x04/0x06~0x09) ┌─────────┐  语音流   ┌──────────┐
│ RA8P1   │ ─────────────────────────→ │  ESP32  │ ────────→ │ 云端大模型 │
│ (CPU0)  │ ←───────────────────────── │         │ ←──────── │  API     │
└─────────┘     UTF-8中文(分行)        └─────────┘  文字结果  └──────────┘
```

## 一、RA8P1 → ESP32（命令，单字节）

RA8P1 发送 **单个字节** 命令给 ESP32（无帧头、无校验、无需应答）。

| 命令字节 | 含义 | 说明 |
|---------|------|------|
| `0x01` | ASR_ON | 开始实时语音转文字 |
| `0x02` | ASR_OFF | 停止实时语音转文字 |
| `0x03` | AI_ON | 开始 AI 智能体对话 |
| `0x04` | AI_OFF | 停止 AI 智能体对话 |
| `0x06` | PPT_ON | 进入 PPT 模式（等待 0x07/0x08） |
| `0x07` | PPT_PREV | PPT 上一页（WiFi TCP 发 `'0'`） |
| `0x08` | PPT_NEXT | PPT 下一页（WiFi TCP 发 `'1'`） |
| `0x09` | PPT_OFF | 退出 PPT 模式（进入静默） |

## 二、ESP32 → RA8P1（数据，UTF-8 分行）

ESP32 把文字结果按 **一行一条字幕** 发送，每行以 **换行符 `\n`（0x0A）** 结尾
（可带 `\r` 0x0D，RA8P1 会忽略）。

```
<UTF-8 中文字幕>\n
<UTF-8 中文字幕>\n
...
```

- 每行内容即一条字幕（一句识别结果 / 一段 AI 回复）。
- 中文采用 **UTF-8 编码**（一个汉字 3 字节）。
- RA8P1 逐字节累积到 `\n` 为止，把整行作为一条字幕处理。
- 单行建议 ≤ 256 字节（RA8P1 侧缓冲 512 字节，超长会截断）。

### 示例

ESP32 发送（十六进制，假设"你好，欢迎使用"）：

```
E4 BD A0 E5 A5 BD EF BC 8C E6 AC A2 E8 BF 8E E4 BD BF E7 94 A8 0A
```

## 三、字幕显示逻辑（RA8P1 侧）

- 收到一行 → 立即更新字幕显示（覆盖上一行）。
- 无新行时保持当前字幕，不自动清除。
- 停止（ASR_OFF / AI_OFF）后停止接收、停止显示。

## 四、会议记录（仅 ASR 模式）

- ASR 模式开启后，收到的每行中文追加到内存缓冲。
- 点击停止录制时，把缓冲内容保存为 SD 卡上的 `record_XX.txt`（XX 顺序递增，如 record_01.txt）。
- 每次上电/开始新录制时，扫描已有 record_*.txt 确定下一个序号（不覆盖）。
- AI 对话模式不保存。

## 五、注意事项

1. **波特率**：两端必须都是 115200 8N1。
2. **无校验**：协议不设 CRC；单字节命令 + 换行分行已足够简单可靠。
3. **命令方向**：命令只由 RA8P1 发给 ESP32；文字数据只由 ESP32 发给 RA8P1，两个方向互不干扰。
4. **测试**：可用 PC 串口助手接 UART2，发送「中文 + 回车(\n)」模拟 ESP32。
