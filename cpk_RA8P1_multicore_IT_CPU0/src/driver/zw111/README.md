# ZW111 指纹模块驱动

## 硬件连接

- **UART6 / SCI6**：P909=RX，P908=TX，**57600 8N1**（ZW111 出厂默认波特率，与 FSP 中 UART6 配置需一致）。
- **TOUCH_OUT**：P907。当前录入/打卡流程用不到它——ZW111 的 `PS_AutoEnroll`/`PS_AutoIdentify` 指令内部会自行探测手指按压（阻塞到按压或超时）。因此该引脚配置为**普通 GPIO 输入**即可，无需中断。

## 协议

见 `指纹模块ZW111/指纹模组产品用户手册_V1.5.1.pdf` 第 3 章：

- 帧头 `0xEF01`，设备地址默认 `0xFFFFFFFF`（4B 大端）。
- 命令包包标识 `01`，应答包包标识 `07`。
- 包长度 = 指令/确认码 + 参数 + 校验和 的总字节数（不含包长度本身）。
- 校验和 = 包标识 + 包长度(2B) + 指令/确认码 + 参数 之和（16 位大端，忽略进位）。
- 多字节参数一律**大端**（高字节在前）。

## 使用的指令

| 指令 | 代码 | 用途 |
| ---- | ---- | ---- |
| `PS_AutoEnroll` | `0x31` | 一站式录入（采集 + 生成特征 + 合并 + 存储） |
| `PS_AutoIdentify` | `0x32` | 一站式验证（采集 + 特征 + 1:N 搜索，ID=0xFFFF） |
| `PS_Empty` | `0x0D` | 清空指纹库（清除全部已录入指纹，成功后录入 ID 计数复位） |
| `PS_HandShake` | `0x35` | 握手探测模块是否在线 |
| `PS_ValidTempleteNum` | `0x1D` | 读有效模板个数，用于断电后恢复录入 ID 计数 |
| `PS_Cancel` | `0x30` | 取消正在进行的自动录入/自动验证（终止流程并返回应答） |

## 模型

- **异步请求 + worker 任务**：录入/打卡会阻塞数秒（等待手指），UI 调用
  `zw111_fingerprint_enroll()`/`zw111_fingerprint_identify()` 只投递请求，
  结果经 `zw111_done_cb_t` 回调返回（worker 任务上下文，栈 2048，优先级 2）。
- **录入 ID 管理**：`s_next_id` 从 1 递增；上电后通过 `PS_ValidTempleteNum`
  恢复（有效模板数 + 1）。录入参数 `bit3=1` 允许覆盖 ID，避免上电计数复位后
  碰撞到已有模板时报错。
- **打卡**：1:N 搜索，成功回调返回 `page_id`（指纹库 ID）与 `score`（得分）。

## 调参

`zw111_fingerprint.c` 顶部：

- `ZW111_ENROLL_TIMES`：录入次数（小面积建议 3）。
- `ZW111_ENROLL_PARAM`：录入参数（默认 `0x0008` = 允许覆盖 ID）。
- `ZW111_IDENTIFY_LEVEL`：比对分数等级（1~5，默认 2）。
- `ZW111_RX_TIMEOUT_MS`：单包应答超时（默认 15s，覆盖等待手指按压）。
